# 码上启航｜沪甬港城社会实践展示网站

上海海事大学“码上启航”实践队成果展示网站，记录上海、宁波两地港航文脉与智慧港口主题社会实践（沪甬联航——从港航文脉到智港未来）。

## 页面结构

| 页面 | 内容 |
| --- | --- |
| `index.html` | 首页：实践主题与双城实践概览 |
| `team.html` | 团队基本情况：“码上启航”实践队介绍 |
| `record.html` | 活动纪实：沪甬双城十站足迹（图文记录） |
| `achievement.html` | 实践总结：从读懂港城到参与未来 |
| `video.html` | 视频成果：沪甬港城影像志（6 段视频） |

## 技术与结构

- 纯静态网站：HTML + CSS + JavaScript，无构建依赖
- `css/`：各页面样式（site.css 为全站公共样式）
- `js/`：site.js（全站脚本）、record.js（纪实数据与渲染）、video.js（视频页脚本）
- `images/`：各站点照片与视频封面（陆续补传）
- `videos/`：视频成果文件（陆续补传）

## 本地运行

直接用浏览器打开 `index.html` 即可，或用 VS Code Live Server 等静态服务器打开本目录。
